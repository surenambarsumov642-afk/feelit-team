# ARISE — план развития

Согласовано в обсуждении. Порядок этапов — по важности.

## Этап 1. Быстрые улучшения
- Смена имени (уникальное, меняется в рейтинге у всех).
- Ввод еды: только название и граммы. Встроенная база продуктов (включая местные блюда), подсказки выбираются только нажатием. Чего нет в базе — оценивает ИИ по тексту («гречка с маслом 150 г»). Числа можно поправить.
- График веса с линией цели и прогнозом.

## Этап 2. Навыки (главное)
**Новый навык — интервью-диагностика (4 блока):**
1. Цель и смысл: результат через 30 дней, который можно показать; зачем это (мотивация, которую Система напоминает в трудные дни); критерий успеха.
2. Где ты сейчас: что пробовал; практический мини-тест вместо самооценки; главная причина прошлых срывов.
3. Ресурсы: минуты в будни/выходные; свободные часы и распорядок; телефон или компьютер; бюджет на платные сервисы; язык материалов.
4. Стиль: видео/текст/практика/примеры; тон Системы (жёстко / строго с поддержкой / мягко); учиться с другом (рейд).

После интервью — профиль ученика (можно поправить) → план на 30 дней → правки → подтверждение «отменить нельзя».

**Механика месяца:** карточка дня (что сделать, где взять — реальные ссылки через поиск, что сдать, зачем) → сдача результата → разбор от ИИ; повторение по расписанию (вопросы по темам 1/3/7 дней назад); план подстраивается, но не отменяется; еженедельный босс; финальный проект. Процент освоения = выполненные дни + боссы + оценка проекта. Штраф за пропуски: минус XP, позорный титул, событие в ленте. Напоминания: утро, выбранное время, вечер. Дневник «что понял сегодня».

**Улучшение навыка (уровни 2, 3, …):** Система сама анализирует прошлый месяц (ошибки на боссах, пропуски, реальное время, проект, дневник, перерыв). Интервью: что применял после и где застревал; входной тест (остаточные знания + слабые места + задание уровнем выше); направление — глубже / новая ветка / заработок; финальный проект заметно сложнее; внешний результат; изменения в жизни; тон. Допуск: прошлый месяц ≥ 60%, иначе месяц закрепления. Долгий перерыв → месяц восстановления. Дерево веток навыка.

**«Выход в мир»:** Ур.1 — на себе и своих; Ур.2 — карта применения (кому нужно, их боли, где искать, ориентир цен), портфолио, предложение, готовые сообщения (на русском, отправляет сам пользователь), тренажёр переговоров с ИИ-клиентом; Ур.3 — первые деньги; Ур.4+ — рост. Квесты реального мира (5 предложений, первый ответ, первый проект, отзыв, первый платный заказ), учёт контактов с напоминаниями, разбор после каждой работы. Без спама и обещаний дохода. Рынок по умолчанию: Ташкент + удалёнка в русскоязычном интернете (уточняется в интервью).

## Этап 3. Соревнование
- Сезоны: неделя / месяц / год (XP за период). Награды: «Охотник недели», редкий титул месяца, годовой победитель — Монарх.
- Лента событий.
- Долгие дуэли (неделя: дни в норме, XP, тренировки; ставка XP).
- Врата: открываются сами, ранги E–S, ограничение по времени, одиночные и рейды с друзьями; редкие титулы; «прорыв» — штраф.

## Этап 4. Система
- Уведомления на телефон (Web Push), звуки и анимации, мотивационные фразы (свои, в стиле Системы — без дословных цитат из аниме).
- Экзамены на ранг (одна ошибка — провал): E→D 7 дн; D→C 14 дн (+50%, 8000 шагов); C→B 21 дн (×2, без сладкого/фастфуда, недельный рейд); B→A 30 дн (10 000 шагов, вес не растёт, отбой до 00:00); A→S 45 дн (100/100/100 + 10 км ежедневно + данж S); Национальный уровень 60 дн без ошибок; Монарх — один на приложение (победитель года).
- Счётчик повторов камерой (на устройстве, видео никуда не уходит): подтверждённая тренировка — полный XP и значок ✓, ручная — половина. Экзамены и живые дуэли — только с камерой.
- Живые дуэли с счётчиком соперника в реальном времени.

## Этап 5. Штрих-коды
Сканер + Open Food Facts + общая база: товар, добавленный одним, появляется у всех.
