# ARISE — учёт калорий в стиле «Системы»

PWA для iPhone: калории по фото (Claude API) и ручной ввод, уровни, ранги E→S, ежедневные квесты, характеристики, достижения и титулы.

## Установка на iPhone
1. Открой в Safari: `https://surenambarsumov642-afk.github.io/feelit-team/calories/`
2. «Поделиться» → «На экран Домой».
3. При первом запуске введи параметры тела, затем в «Настройках» — ключ Claude API (console.anthropic.com → API Keys).

## Как устроено
- `index.html`, `styles.css`, `app.js` — интерфейс и логика «Системы» (прогресс считается из записей, хранится в localStorage).
- `ai.js` — распознавание фото: модель `claude-opus-5-5`, структурированный JSON-ответ, авто-фолбэк при отказе.
- `vendor/anthropic.mjs` — официальный SDK `@anthropic-ai/sdk` 1.8.0, собранный в один файл:
  `npm i @anthropic-ai/sdk esbuild && npx esbuild entry.js --bundle --format=esm --platform=browser --minify --outfile=anthropic.mjs`
  (entry.js реэкспортирует `default` и классы ошибок).
- `sw.js` — офлайн-кэш. При изменении файлов поменяй `CACHE` в sw.js.

## Правила прокачки
| Действие | XP |
|---|---|
| Каждая запись (до 10 в день) | +5 |
| Квест «3 приёма пищи» | +30 |
| Квест «Норма белка» (≥90%) | +40 |
| Квест «Норма калорий» (85–105%, при наборе до 110%) | +60 |
| Все три квеста | +50 |
| Штраф: день без записей | −30 |
| Штраф: перебор >115% нормы | −20 |

Уровень N→N+1 стоит `100 + 25·(N−1)` XP. Ранги: E 1–9, D 10–19, C 20–34, B 35–49, A 50–69, S 70+.
